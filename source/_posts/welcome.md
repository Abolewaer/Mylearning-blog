一份学习记录，可以从一个问题、一段代码，或者一次终于想明白的瞬间开始。

这是博客的示例文章。之后，我会在这里整理自己的笔记、阅读和实践成果。

<!-- more -->

## 给每一次学习留一个入口

我希望每篇笔记都能回答三个问题：

1. **我想解决什么问题？** 先写清楚背景。
2. **我做了什么？** 记录推导、代码和实践过程。
3. **我学到了什么？** 总结结论，也保留疑问。

## 从小的实践开始

代码、图片和表格可以和正文一起保存在文章中。

```python
def learn_by_doing(question):
    return {"问题": question, "状态": "开始探索"}
```

| 内容类型 | 适合记录什么 |
| --- | --- |
| 学习笔记 | 概念理解、课程总结、推导 |
| 论文阅读 | 问题、方法、实验与思考 |
| 项目实践 | 目标、实现、结果与复盘 |
